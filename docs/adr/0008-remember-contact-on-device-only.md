# 參加過的人少打字：只在報名者自己的手機記住資料，後端不跨場次保留

參加過的人報名下一場時，要重打暱稱和聯絡方式。我們考慮過讓試算表長期保留聯絡方式，輸入手機就自動帶出其他資料，但這樣做有三個問題：

- 違反報名表上寫的承諾（「僅供本場活動使用」「活動結束後一個月內刪除」）。要改說明、重新取得同意，已經報名過的人的資料也不能事後改成保留。
- 用手機號碼查詢，等於任何人輸入別人的手機號碼，都能查到對方的暱稱和 LINE ID。要擋住就得加驗證碼，靜態網頁加 Apps Script 的架構做不到。
- 試算表累積的個資越多，帳號被盜或不小心分享時的傷害越大。

所以只在報名者自己的手機記住：報名成功後由報名者選擇要不要記住，資料存在那支手機的瀏覽器，不送到後端，主辦者看不到。試算表的一個月內刪除照舊。

## Consequences

- 換手機、換瀏覽器、清除資料或使用無痕模式時要重新填。LINE 內建瀏覽器有時會清掉這些資料。
- 共用手機或幫朋友報名時，可能帶入別人的資料。所以：成功後才問、資料不同時預設不換、表單上隨時可以「清除」、從「幫朋友報名」進入表單時不帶入。
- 一年沒再報名就自動清除，不會無限期留在手機上。
- 只改網頁，不動 `Code.gs`，不用重新部署後端。
