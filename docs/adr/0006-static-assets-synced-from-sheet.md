# 預覽圖與行事曆檔是固定檔案，由本機工具從試算表的公開資料產生

LINE 抓分享預覽、iPhone 匯入行事曆都不會執行網頁的 JavaScript，所以 `og.png`、`event.ics` 和 `index.html` 的分享文字只能是網站上的固定檔案，不會跟著試算表變。我們不讓後端產生它們（後端刻意不能連外，也無法改 GitHub 上的檔案，見 [0001](0001-static-page-with-sheet-backend.md)），而是用 `tools/sync_event.py` 讀取網頁讀的同一份公開資料來產生，日期、星期、時間、地點都不再手動輸入。預覽圖裡記錄了產生時的日期和地點，GitHub Actions 每天用 `--check` 比對一次，過期時 GitHub 會寄信通知。

## Consequences

- 預覽圖網址的版本號是 `og.png` 內容的雜湊值，圖一變就換網址，LINE 會重新抓取。
- `--badge`、`--note` 這類只出現在預覽圖的文字不在試算表裡，下一次產生時要重新指定，否則會被拿掉。
- 每天的檢查只比對日期、時間和地點；其他文字（例如費用）改了不會觸發通知。
