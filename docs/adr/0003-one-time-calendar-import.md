# 行事曆一律一次性匯入，Apple 用網站上的固定 .ics 檔

訂閱式行事曆可以在改期時自動更新，但更新延遲不可控、不會通知使用者，iPhone 預設還會移除訂閱行事曆的提醒，等於改期後大家默默看到新日期、卻沒有提醒。所以只提供一次性匯入，改期時由主辦者個別通知。iOS 不接受網頁臨時產生的檔案，所以 Apple 行事曆連到網站上真實存在的 `event.ics`；網頁會比對它的時間和目前設定，不一致就隱藏按鈕。

## Considered Options

- **網頁用 data: 或 Blob 臨時產生 .ics**：iOS 不接受網頁臨時產生的行事曆檔。
- **LINE 內建瀏覽器直接開 .ics**：LINE 會把它當成「訂閱行事曆」並改用 http，GitHub Pages 轉址後訂閱失敗（iOS 26 實測）。所以在 LINE 裡改成複製連結、請報名者貼到 Safari。
