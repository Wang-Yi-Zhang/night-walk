# 設定檢查只提醒，不擋下也不改變讀取規則

「設定」分頁填錯時（例如報名截止少了時間），原本會靜靜地退回預設行為：不截止、行事曆按鈕消失。我們選擇在試算表上標出問題（「檢查」欄、紅色儲存格、編輯當下的提示、選單「檢查設定」），而不是拒絕讀取或停止報名：主辦者在活動前一刻改設定時，一個格式錯誤就讓整個報名停擺，代價比「不截止」更大。提醒也不放進公開資料，因為報名者看不懂、也不該看到主辦的設定問題。

## Consequences

- 讀取規則和檢查規則是兩套程式碼：例如 `10人` 仍讀成 10，但會被標示。修改其中一套時，要確認另一套的說法還對。
- 這只涵蓋主辦者會打開試算表的情況；預覽圖和行事曆檔的過期另外由 [0006](0006-static-assets-synced-from-sheet.md) 處理。
