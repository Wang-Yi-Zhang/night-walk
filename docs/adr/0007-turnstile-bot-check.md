# 用 Cloudflare Turnstile 防止灌報名，連不上時不放行

後端網址寫在公開的 `config.js` 裡，任何人都能繞過網頁直接送出報名。honeypot 只擋得住亂填表單的機器人，每分鐘 20 筆的限制又是全站共用（Apps Script 拿不到來源 IP），所以有人用一批假手機號碼，幾秒內就能佔滿正取和候補，持續送出還會把真的報名者擋在外面。

我們選擇 Cloudflare Turnstile：免費，大多數報名者看不到任何題目。reCAPTCHA v3 一樣要開對外連線的權限，但它用分數判斷，門檻不好調，對每場只有 15 個名額的活動不划算。

- 密鑰放在 Apps Script 的指令碼屬性，不放試算表：理由跟通知信收件人寫死在程式裡一樣，有試算表編輯權的人不該改得到。
- 沒設定密鑰就跳過驗證，所以能先部署、再啟用；出問題時刪掉指令碼屬性就能停用。
- 驗證放在欄位檢查之後、上鎖之前：填錯欄位不會用掉 token，沒通過的請求也不占鎖、不計入每分鐘的次數。
- 連不上 Cloudflare 時擋下報名（fail-closed）：如果改成放行，攻擊者只要讓驗證出錯就能繞過。Cloudflare 故障時暫時不能報名，這個代價比較小。

## Consequences

- 後端多了「連線至外部服務」的權限（`UrlFetchApp`），重新部署時要重新授權。`@OnlyCurrentDoc` 不受影響。
- 報名者的瀏覽器資訊會送到 Cloudflare。
- 擋不住真人手動灌報名，也擋不住付費的解題服務；每筆報名的通知信仍是主辦者發現異常的主要管道。
- LINE 內建瀏覽器和擋廣告外掛可能讓驗證失敗，這時報名者會看到「請直接聯絡主辦」。
