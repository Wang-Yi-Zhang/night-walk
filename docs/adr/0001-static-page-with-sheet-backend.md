# 用靜態網頁＋綁定試算表的 Apps Script，不用 Google 表單

Google 表單無法在額滿時精準截止、同時送出會超收，也沒有候補；把試算表「發佈到網路」讓網頁讀人數，又會連聯絡方式一起公開。所以改成 GitHub Pages 上的靜態報名網頁，後端是綁定在主辦者試算表上、以主辦者身分執行的 Apps Script：寫入時加鎖保證不超收，讀取只回傳人數和暱稱。試算表仍然是唯一的資料來源，主辦者不用學新工具。

## Consequences

- 後端權限刻意壓到 `@OnlyCurrentDoc` 加 `MailApp`，所以後端不能連外（例如讀 GitHub 上的檔案），需要外部資料的功能只能放在網頁或本機工具（見 [0006](0006-static-assets-synced-from-sheet.md)）。
- 更新後端要由主辦者手動貼程式碼並部署新版本；前後端都要改時，先部署相容舊網頁的後端。
